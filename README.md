# What's Left in My Fridge 🧊

เว็บช่วยลดขยะอาหาร ใส่ของในตู้เย็นพร้อมวันหมดอายุ แล้วเว็บจะแนะนำเมนูที่ใช้ของใกล้หมดอายุก่อน

ลิงก์ผลงาน: https://whats-left-fridge-icyr.vercel.app

## ปัญหาที่เลือก
หลายครั้งเราลืมของในตู้เย็นจนหมดอายุ หรือมีของเหลืออยู่แต่ไม่รู้จะทำอะไรกิน ทำให้ทิ้งอาหารโดยไม่จำเป็น เว็บนี้จึงช่วยจดของในตู้เย็น เตือนว่าอะไรใกล้หมดอายุ และบอกว่าควรทำเมนูอะไรก่อน

## ฟีเจอร์
- สมัครสมาชิกและเข้าสู่ระบบ แต่ละคนมีตู้เย็นของตัวเอง
- เพิ่มและลบของในตู้เย็น (ชื่อ จำนวน หน่วย วันหมดอายุ) เรียงตามใกล้หมดอายุก่อน ของที่เหลือไม่เกิน 3 วันขึ้นสีแดง
- เมนูแนะนำจากสูตรในฐานข้อมูล ให้คะแนนสูตรที่ใช้ของใกล้หมดอายุสูงกว่า บอกว่ามีวัตถุดิบอะไรแล้วและยังขาดอะไร พร้อมวิธีทำ
- โหมดจับคู่แปลกๆ หยิบของที่ใกล้หมดอายุที่สุดมาจับคู่กับอีกอย่างเพื่อเสนอไอเดียเมนูสร้างสรรค์

## เทคโนโลยีที่ใช้
- หน้าเว็บ: HTML, CSS, JavaScript (ไฟล์ index.html, style.css, app.js)
- ฐานข้อมูลและระบบล็อกอิน: Supabase (Auth, Postgres, Row Level Security)
- เก็บโค้ด: GitHub
- เผยแพร่เว็บ: Vercel (deploy อัตโนมัติทุกครั้งที่ commit)
- ผู้ช่วย AI: Claude

## ฐานข้อมูล
- fridge_items: ของในตู้เย็นของผู้ใช้แต่ละคน มี policy ให้เข้าถึงได้เฉพาะเจ้าของข้อมูลที่ล็อกอินแล้ว
- recipes: ชื่อเมนู ประเภทอาหาร และขั้นตอนทำ
- recipe_ingredients: วัตถุดิบของแต่ละสูตร เชื่อมกับ recipes ด้วย recipe_id

## กระบวนการใช้ AI
1. วางแผนก่อนทำ: แบ่งงานเป็นขั้น เริ่มจากทดสอบว่าระบบเชื่อมกันได้ (GitHub, Vercel, Supabase) ด้วยหน้าเว็บเล็กๆ ก่อน แล้วจึงสร้างฟีเจอร์จริงทีละส่วน
2. ทำทีละขั้นและทดสอบทุกขั้น: ให้ AI เขียนโค้ดทีละส่วน (ฟอร์มเพิ่มของ รายการเรียงตามวันหมดอายุ แนะนำเมนู โหมดจับคู่แปลกๆ ตกแต่งหน้าตา) แล้วทดสอบบนเว็บจริงและแคปหน้าจอส่งให้ AI ดูผล
3. ใช้ AI หาสาเหตุเมื่อมีข้อผิดพลาด ตัวอย่างที่เจอจริง
   - ช่องเลือกวันที่ล้นกรอบบน Safari ของ iPad แก้ด้วย CSS
   - ปุ่มเข้าสู่ระบบกดไม่ได้ เพราะไฟล์ app.js มีวงเล็บเกินและโค้ดส่วนท้ายขาด ทำให้สคริปต์ทั้งไฟล์ไม่ทำงาน
   - ฟีเจอร์อ่านรูปขึ้น error ว่าไม่มี API key ทำให้รู้ว่าปัญหาอยู่ฝั่งหลังบ้าน ไม่ใช่โค้ดหน้าเว็บ
4. ตัวอย่าง prompt ที่ใช้ (ปรับให้ตรงกับที่ใช้จริง)
   - [ใส่ prompt จริง 2-3 ข้อความของคุณ]

## การแบ่งงาน
- [ชื่อคุณ]: หน้าบ้านทั้งหมด (หน้าตา ฟอร์ม การแสดงเมนู ระบบล็อกอินฝั่งหน้าเว็บ)
- [ชื่อเพื่อน]: หลังบ้าน (Supabase ฐานข้อมูล ตาราง สูตรอาหาร policy ความปลอดภัย)

## สิ่งที่ยังไม่ได้ทำ / ต่อยอดได้
- อ่านวัตถุดิบจากรูปถ่ายด้วย AI: ทดลองทำแล้วแต่ยังไม่รวมในเวอร์ชันส่ง
- แจ้งเตือนของใกล้หมดอายุ และเพิ่มจำนวนสูตรอาหาร
